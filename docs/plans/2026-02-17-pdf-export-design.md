# PDF Export Service — Design

> Server-side PDF generation producing professional, branded tax advisory reports using ReportLab.

---

## Scope

Add a PDF export service to the Helio API that generates professional, colored, business-grade tax reports. The report compiles all dashboard data — client information, income summary, tax computation by band, national insurance, personal allowance status, HICBC, observations with savings, and scenario comparisons — into a structured, branded document. Wire the existing Export buttons in the frontend to trigger generation and download.

---

## Architecture

**Approach: ReportLab (Server-side Python)** — Programmatic PDF generation using ReportLab's `platypus` layout engine. Pure Python, no system dependencies, sub-100ms generation. Full control over colors, fonts, tables, and page layout.

**Flow:**
1. Frontend sends POST with `dashboardData` + `client` + optional `scenarios` to `/api/exports/tax-report`
2. API router validates input, calls the PDF service
3. PDF service generates the report in-memory (BytesIO)
4. API returns `StreamingResponse` with `application/pdf` content type
5. Frontend triggers browser download

---

## 1. API Endpoint

```
POST /api/exports/tax-report
```

**Request body:**
```typescript
{
  client: {
    first_name: string;
    last_name: string;
    email: string;
    ni_number?: string;
    utr?: string;
    date_of_birth?: string;
    region?: string;
    employment_status?: string;
  };
  taxPosition: { /* same shape as TaxComputationData.taxPosition */ };
  dashboardData: { /* same shape as TaxComputationData.dashboardData */ };
  scenarios?: ScenarioData[];
}
```

**Response:** `application/pdf` binary stream with `Content-Disposition: attachment; filename="helio-tax-report-{client_name}-{tax_year}.pdf"`

## 2. Report Structure (Pages)

### Page 1: Cover
- Helio branding (company name in brand color, tagline)
- Client name (large, prominent)
- Tax year (e.g. "2024/25")
- Report generation date
- "Confidential" notice

### Page 2+: Report Body

**Section 1: Client Information**
- Name, email, NI number, UTR, DOB, region, employment status
- Displayed as a clean key-value table with alternating row shading

**Section 2: Income Summary**
- Table of income sources (type, label, amount)
- Total gross income highlighted

**Section 3: Tax Computation**
- Taxable income after personal allowance
- Income tax by band table (band name, income in band, rate, tax)
- Total income tax
- Dividend tax (if applicable)

**Section 4: National Insurance**
- Class 1, 2, 4 breakdown
- Total NI

**Section 5: Adjusted Net Income & Personal Allowance**
- Adjusted net income
- Personal allowance amount and status (full/tapered/lost)
- Visual status indicator (color-coded dot)

**Section 6: High Income Child Benefit Charge** (if applicable)
- Child benefit annual amount
- Clawback percentage
- HICBC charge
- Net benefit retained

**Section 7: Tax Summary**
- Income tax + NI + HICBC = Total tax
- Effective rate, marginal rate
- Highlighted summary box

**Section 8: Observations & Recommendations**
- Each observation as a card-like block:
  - Title, category badge, severity indicator
  - Description
  - Potential saving (highlighted if > 0)
  - Recommended action

**Section 9: Scenario Comparisons** (if scenarios provided)
- Side-by-side table: Current vs Proposed
- Fields: gross salary, sacrifice, income tax, NI, HICBC, total tax, personal allowance
- Savings row highlighted in green

### Footer (every page)
- Page numbers
- "Generated by Helio · {date}"
- "This report is for advisory purposes only"

## 3. Visual Design

**Colors:**
- Brand primary: `#5C7CFA` (Helio brand blue)
- Brand dark: `#364FC7`
- Section headers: brand primary background with white text
- Table headers: light brand tint background
- Alternating rows: white / very light grey (`#F8F9FA`)
- Savings/positive: `#40C057` (green)
- Warnings/HICBC: `#FD7E14` (amber)
- Alerts/lost PA: `#FA5252` (red)

**Typography:**
- Headings: Helvetica Bold
- Body: Helvetica
- Monospace numbers: Courier for financial figures (tabular alignment)
- Cover title: 28pt, body: 10pt, captions: 8pt

**Layout:**
- A4 portrait
- 2cm margins all sides
- Section dividers with brand-colored thin lines
- Key-value pairs in two-column layout
- Financial tables with right-aligned numbers

## 6. Performance

- ReportLab generates in-memory (no temp files on disk)
- BytesIO buffer streamed directly to response
- No database queries in the export endpoint — all data sent from frontend
- Stateless — horizontally scalable, no session required
- Expected generation time: <200ms for a full report
